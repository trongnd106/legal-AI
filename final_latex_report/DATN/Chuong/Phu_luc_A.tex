Phụ lục này trình bày cấu hình triển khai của hệ thống, tập trung vào file \texttt{data/labor-law/settings.yaml} --- điểm cấu hình trung tâm cho pipeline indexing và truy vấn GraphRAG. Các tham số được chọn nhằm: (i)~bảo toàn đơn vị pháp lý khi chunking, (ii)~giảm chi phí LLM khi indexing, (iii)~cân bằng chất lượng retrieval và latency khi truy vấn.

\section{Tổng quan cấu hình}
\label{appendix:a-overview}

File \texttt{settings.yaml} điều khiển toàn bộ pipeline GraphRAG: mô hình LLM/embedding, định dạng đầu vào, chunking, trích xuất đồ thị (Lớp~2), sinh community report, và tham số Local/Global Search. Lớp~1 (cấu trúc pháp lý xác định) \textbf{không} nằm trong file này mà được xây dựng bởi \texttt{scripts/01\_prepare\_data.py} và hợp nhất qua \texttt{scripts/02\_merge\_structural\_graph.py}.

Đổi model yêu cầu re-index nếu muốn tái tạo toàn bộ Lớp~2; cache JSON (\texttt{data/labor-law/cache/}) giúp giảm chi phí khi chạy lại.

\section{Đầu vào, đầu ra và cache}
\label{appendix:a-io}

\textbf{Định dạng đầu vào:} GraphRAG đọc file JSONL từ \texttt{data/labor-law/chunks/}. Mỗi dòng là một Điều luật với các trường:

\begin{itemize}[nosep, leftmargin=*]
    \item \texttt{id}: định danh chuẩn (VD: \texttt{BLLĐ\_2019\_Điều\_35})
    \item \texttt{van\_ban}, \texttt{so\_dieu}, \texttt{tieu\_de}, \texttt{chuong\_so}, \texttt{norm\_type}
    \item \texttt{noi\_dung}: toàn văn Điều (gửi vào LLM extraction)
    \item \texttt{khoans[]}: danh sách Khoản (metadata Lớp~1)
\end{itemize}

\textbf{Cache:} Kiểu \texttt{json}, lưu tại \texttt{data/labor-law/cache/}. Mỗi lần gọi LLM được cache theo hash input --- khi re-index sau khi sửa prompt, cần xóa cache tương ứng hoặc toàn bộ thư mục cache.

\textbf{Output:} Artifacts Parquet trong \texttt{data/labor-law/output/} (\texttt{entities.parquet}, \texttt{relationships.parquet}, \texttt{text\_units.parquet}, \texttt{community\_reports.parquet}\ldots). Sau merge L1+L2: \texttt{merged\_entities.parquet}, \texttt{merged\_relationships.parquet}.

\section{Biến môi trường và lệnh triển khai}
\label{appendix:a-deploy}

\textbf{Biến môi trường bắt buộc} (file \texttt{.env}, không commit):
\begin{itemize}[nosep, leftmargin=*]
    \item \texttt{OPENROUTER\_API\_KEY} --- LLM và embedding
    \item \texttt{NEO4J\_URI}, \texttt{NEO4J\_USERNAME}, \texttt{NEO4J\_PASSWORD} --- tuỳ chọn, nếu bật Neo4j
\end{itemize}

\textbf{Quy trình indexing đầy đủ:}
\begin{enumerate}[nosep, leftmargin=*]
    \item \texttt{python scripts/01\_prepare\_data.py --verify}
    \item \texttt{graphrag index --root data/labor-law}
    \item \texttt{python scripts/02\_merge\_structural\_graph.py --root data/labor-law}
    \item \texttt{uvicorn api.main:app --host 0.0.0.0 --port 8000}
\end{enumerate}
