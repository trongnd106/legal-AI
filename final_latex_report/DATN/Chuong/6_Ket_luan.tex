\section{Hạn chế}
\label{section:5.2}
\begin{itemize}[nosep, leftmargin=*]
    \item Corpus và domain coverage hẹp
    \item Chi phí/thời gian indexing cao ($\sim$4000--5000 LLM calls)
    \item Phụ thuộc LLM gateway + Ollama local
    \item Graph tĩnh --- cập nhật văn bản cần re-index
    \item Global Search latency cao; multi-hop/temporal/rule validator chưa tích hợp đầy đủ vào API
\end{itemize}
